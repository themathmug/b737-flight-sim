# Boeing 737 Study-Level Flight Simulator

## Project Description
This project aims to create a detailed and study-level flight simulator for the Boeing 737 aircraft, focusing on realism and accuracy to provide an immersive flying experience.

## Features Overview
- **Realistic Flight Dynamics**: Accurate representation of the Boeing 737's flight behavior.
- **Comprehensive Cockpit Simulations**: Fully interactive cockpit with all major controls and displays.
- **Multiple Scenarios**: Different flying scenarios, including takeoff, landing, and in-flight emergencies.
- **Modular Design**: Easily extendable architecture to allow for additional features and enhancements.

## Quick Start Instructions
1. Clone the repository: `git clone https://github.com/themathmug/b737-flight-sim.git`
2. Navigate into the project directory: `cd b737-flight-sim`
3. Follow the setup instructions in the `INSTALL.md` file for dependencies and configurations.
4. Start the simulator: `run_simulator` command.

Happy flying!
